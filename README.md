# Draft Lab

Прототип помощника по драфту Dota 2: React + Vite, клиент организован по слоям FSD.

## Запуск

Нужен Node.js 20.19+ или 22.12+. В PowerShell при запрете выполнения скриптов используйте `npm.cmd`:

```sh
npm install
npm run server
```

В другом терминале запустите `npm run dev` и откройте адрес, который покажет Vite. API доступен только локально на порту 3001; Vite перенаправляет запросы `/api` на него. Для проверки сборки — `npm run build`.

## Данные и ограничения

Для рекомендованных героев сервер получает общую статистику из HTML страницы Dota2ProTracker: победы, матчи, период и минимальный MMR. Данные кэшируются 15 минут; время получения и ссылка на страницу показываются рядом. Страница использует внутренний формат, поэтому парсер может перестать работать без предупреждения. Это экспериментальная интеграция, не официальный API; перед публичным запуском следует проверить условия использования и допустимость автоматических запросов. Dotabuff ответил Cloudflare 403 и не подключён.

Список героев, роли, контрпики, связки и билды — ограниченные демонстрационные правила; они не обновляются по патчу и могут устареть. Статистика со страницы относится ко всем позициям и не участвует в ранжировании. Порядок рекомендаций определяется количеством совпавших ручных правил, при равенстве — именем. Это не прогноз победы.
