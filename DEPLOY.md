# Публикация на Render

1. Создайте репозиторий GitHub и загрузите проект. Файл `.env.local` исключён в `.gitignore` и не должен попадать в репозиторий.
2. На Render выберите **New → Web Service** и подключите репозиторий.
3. Выберите бесплатный план, если он доступен. Укажите Build Command: `npm install && npm run build`; Start Command: `npm start`.
4. В разделе Environment добавьте переменную `STRATZ_TOKEN`, скопировав значение из локального `.env.local`. Не публикуйте токен в коде.
5. Запустите создание сервиса. После завершения откройте выданный Render адрес и поделитесь им с друзьями.

Бесплатный сервер может засыпать после простоя; первое открытие после этого будет медленнее. Использование API регулируется ограничениями STRATZ.
